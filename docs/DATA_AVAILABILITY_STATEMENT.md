# Data and Code Availability statement

The 528-case nonlinear finite-element dataset, processed diagnostic evidence, Bayesian-network and benchmark-model analysis records, leakage-control results, strict node-removal and topology-sensitivity outputs, posterior-calibration data, leave-one-geometry-out results, processed experimental demonstration inputs, and scripts required to reproduce the principal tables and figures are openly available through the Re-BUILD-EU project GitHub repository. Experimental information derived from previously published physical tests is included only in processed form required for reproducibility; the original experimental publications remain the primary sources.
