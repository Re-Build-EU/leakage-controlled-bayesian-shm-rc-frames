# Re-BUILD-EU: Leakage-controlled Bayesian SHM of earthquake-damaged RC frames

This repository package contains the data, analysis outputs, model specification, validation records, and reproduction utilities supporting the study:

**Leakage-controlled Bayesian structural health monitoring of earthquake-damaged RC frames using mechanism-aware evidence and experimental demonstration**

Authors: Abdul Ghafar Wahab, Francesco Clementi, Zhong Tao  
Project: **Re-BUILD-EU**, Marie Skłodowska-Curie Actions Postdoctoral Fellowship, Horizon Europe, Grant Agreement No. **101281012**.

## What is included

The package is designed to be self-contained for auditing the reported results and regenerating the principal tables and figures. It includes:

- the final 528-case nonlinear finite-element response dataset;
- complete fold-level and summary results for repeated stratified 3 × 5-fold validation;
- same-scalar leakage scores for the Bayesian network and benchmark classifiers;
- out-of-fold Bayesian posterior probabilities and calibration metrics;
- leave-one-geometry-out results for all eight structural configurations;
- strict same-scalar node-removal and Bayesian-network topology sensitivity outputs;
- threshold and nonlinear-region-length sensitivity results;
- processed experimental evidence and posterior probabilities for EF, RF, DJ-1, and DJ-2;
- scripts that validate the package, summarize the dataset, regenerate manuscript tables and figures, and provide a reference implementation of the final inference protocol;
- data provenance, variable definitions, modelling assumptions, and a step-by-step reproduction tutorial.

The canonical dataset is `data/simulation/fem_dataset_528.csv`. The canonical numerical result files are those under `results/`. These archived outputs provide exact traceability to the reported manuscript values.

## Quick start

Python 3.10+ is recommended.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt

python scripts/00_verify_package.py
python scripts/01_dataset_summary.py
python scripts/02_reproduce_tables.py
python scripts/03_reproduce_figures.py
```

After these commands, derived summary tables are written to `generated/tables/` and figures to `figures/`.

For a full protocol-level model recomputation, install the Bayesian-network dependencies and run:

```bash
pip install -r requirements-model.txt
python scripts/04_reference_model_protocol.py --help
# Optional end-to-end recomputation (writes to recomputed/)
python scripts/05_recompute_analysis.py --mode all
```

The complete procedure is described in `docs/TUTORIAL.md`.

## Core results reproduced by the package

Under leakage-controlled repeated 3 × 5-fold validation, the Bayesian network achieved macro F1 values of 0.626 for damage state, 0.741 for stiffness loss, and 0.645 for residual capacity. Full-evidence macro F1 values were 0.911, 0.933, and 0.907, respectively. Leave-one-geometry-out mean macro F1 values were 0.501, 0.601, and 0.552. Expected calibration errors were 0.138, 0.104, and 0.070.

The experimental demonstration produced probabilities of significant damage of 0.943, 0.888, 0.897, and 0.897 for EF, RF, DJ-1, and DJ-2, respectively, and probabilities of substantial stiffness loss of 0.996, 0.995, 0.955, and 0.955.

## Experimental data provenance

The experimental information used in the simulation-to-experiment demonstration comes from previously published physical tests. This repository does **not** redistribute publisher PDFs or claim the experiments as newly generated data. It provides only the processed evidence required to reproduce the present analysis. See `docs/DATA_PROVENANCE.md` and `data/experimental/README.md`.

## Repository layout

```text
.
├── data/
│   ├── simulation/              # final 528-case FE response dataset
│   ├── experimental/            # processed source-supported experimental evidence
│   └── reference/               # source citation metadata
├── results/
│   ├── repeated_cv/             # leakage and repeated 3 × 5-fold results
│   ├── calibration/             # OOF posterior probabilities and calibration
│   ├── geometry_transfer/       # leave-one-geometry-out results
│   ├── sensitivity/             # strict leakage, topology, thresholds, hinge length
│   ├── mechanism/               # member-response statistics
│   └── figure_data/             # compact data used for manuscript figures
├── generated/tables/            # regenerated by scripts/02_reproduce_tables.py
├── figures/                     # regenerated by scripts/03_reproduce_figures.py
├── scripts/                     # package verification and reproduction utilities
├── docs/                        # tutorial, methods, provenance, result map
├── notebooks/                   # quick-start notebook
└── manifest/                    # checksums and validation record
```
